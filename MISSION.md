# Mission: Lean for Undergraduate Mathematics and Functional Programming

## Why

I want to learn Lean to prove undergraduate abstract mathematics theorems and
to solve functional programming katas. I start with set theory and logic, then
progress to real analysis, topology, and abstract algebra. The FP katas build
programming fluency; the theorem proving builds formal reasoning skills — each
reinforces the other.

## Success looks like

- Solve ~20 functional programming katas in Lean covering recursion,
  higher-order functions, algebraic data types, and custom inductive types
- Prove propositional logic tautologies and De Morgan's laws (logic and sets)
  in Lean
- Prove basic set theory identities: commutativity, associativity,
  distributivity, De Morgan's laws for sets
- Prove relation and function properties: equivalence relations,
  injectivity, surjectivity
- Formalize theorems from undergraduate textbooks in real analysis,
  topology, and abstract algebra

## Constraints

- Docker-based dev environment with Lean 4.29.0
- No prior functional programming, type theory, or formal logic experience —
  everything built from first principles
- Primary learning through hands-on katas and exercises in this workspace
- Preference for learning by doing: each new concept is introduced through an
  exercise the user completes

## Out of scope

- Postgraduate-level mathematics (research-level math, advanced Mathlib
  contributions)
- Category theory
- Metaprogramming and custom tactic development
- Performance optimization of Lean code
- Compiler internals and kernel design
